# Game-theory cases

Two 2 x 2 games are encoded as payoff matrices and solved with `nashpy`. The accompanying analysis compares best responses, pure-strategy Nash equilibria, and Pareto considerations. After installing the repository requirements, run from the repository root:

```bash
python hw05-game-theory/nash_equilibrium.py
```

The [analysis](analysis.md) explains the hypothetical utility values, best
responses, equilibria, and Pareto comparisons. The values are modeling
assumptions rather than empirical estimates.
